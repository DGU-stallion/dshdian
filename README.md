# dshdian

将 [DSH (DeepSeek Harness)](https://github.com/DGU-stallion/dshdian) 作为 AI 协作者嵌入 Obsidian 的桌面端插件。

核心差异化：通过对话生成**独立的 Obsidian 原生插件**——不绑定任何运行时，卸载 dshdian 后生成的插件仍可正常运行。

## 功能特点

三种工作模式：

| 模式 | 用途 | 权限 |
|------|------|------|
| 聊天 | 只读问答，基于 vault 内容回答问题 | 只读 |
| 管家 | 全能 vault 操作（创建/移动/修改笔记、管理文件等） | 读写 |
| 创造 | 通过对话生成完整的 Obsidian 原生插件 | 读写 + 插件目录 |

- 基于 git 状态的动态审批策略——dirty worktree 时自动提升确认级别
- 仅支持桌面端（依赖本地进程和文件系统访问）

## 前置要求

- Obsidian 桌面版（≥ 1.5）
- DSH Harness 进程（本地运行）
- Git（用于审批策略的状态检测）
- Node.js ≥ 18（开发时）

```
              ▼

```
