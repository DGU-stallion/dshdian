## Key architectural decisions (read CONTEXT.md and docs/adr/ for full detail)

- **External DSH Harness process** (port 3180), dshdian is thin client via HTTP API + SSE
- **No MCP Server** — vault ops via `obsidian` CLI (shell tool); @references via frontend injection
- **3 modes**: Chat (readonly), Butler (full CLI + git-aware approval), Creator (generate native plugins)
- **Native plugin generation**: TypeScript → dshdian built-in esbuild → preview in `_dshdian_preview/` → confirm install
- **Git-aware approval**: has git = lenient (reversible); no git = strict (confirm everything)
- **Versioning**: generated plugin source in vault git, compiled output in .gitignore
