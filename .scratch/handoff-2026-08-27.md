## 架构关键路径

```
Plugin onload
  → DshProcessManager.start()
    → findDsh() (npx cache / PATH)
    → ensureProfile("dshdian") 
    → spawn dsh --profile dshdian --port 3180 --no-open
    → healthCheck GET / 轮询
  → 用户点击发送
    → HarnessClient.sendMessage(sessionId, text) 
      → POST /api/session.prompt (JSON-RPC)
    → HarnessClient.connectMux() 
      → WebSocket ws://localhost:3180/api/events.mux  ← 这里断了
      → 解析 mux frames → StreamEvent → view 渲染
```

## DSH API 参考（已验证可用）

```bash
# 创建 session
POST /api/session.create
Body: { type:"client-request", rpcId:"<uuid>", method:"session.create", payload:{ cwd:"/path" } }
Response: { result: { ok:true, value: { sessionId:"session-xxx" } } }

# 发送消息
POST /api/session.prompt
Body: { type:"client-request", rpcId:"<uuid>", method:"session.prompt", payload:{ sessionId:"...", mode:"queue", content:[{type:"text",text:"..."}] } }

# 事件流（问题所在）
WebSocket ws://localhost:3180/api/events.mux

# 列出 sessions
POST /api/session.list

# 取消运行
POST /api/session.cancel
```
